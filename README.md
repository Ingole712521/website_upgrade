## 💡 Why I Built This

Instead of only submitting a résumé and waiting for an opportunity, I wanted to demonstrate how I approach a real product problem.

I reviewed the existing **zCon Solutions** website and rebuilt the public-facing experience with a stronger focus on:

* Better visual hierarchy
* Cleaner component architecture
* Improved UX consistency
* Reusable UI patterns
* Modern frontend development practices
* A more polished and product-focused experience

This project is **not intended to claim that the existing website is wrong**.

The purpose is to show how I think when given an existing product:

> **Understand → Identify opportunities → Build → Polish → Ship**

I wanted the work itself to communicate my approach rather than relying only on a résumé.

---

## 🎯 What I Focused On

### 1. Cleaner UI Architecture

The application was structured around reusable components and sections instead of creating every page independently.

This makes the codebase:

* Easier to maintain
* Easier to extend
* More consistent
* Faster to iterate on

### 2. Stronger Visual Hierarchy

The redesign focuses on making important information easier to discover.

I worked on:

* Typography
* Spacing
* Section hierarchy
* CTA placement
* Content grouping
* Responsive layouts
* Visual consistency

### 3. UX & Consistency Improvements

While rebuilding the website, I identified several areas where the user experience could be made more consistent.

The rebuild addresses areas such as:

* Repeated UI patterns
* Section spacing
* Content presentation
* Navigation experience
* Responsive behavior
* Interaction states

### 4. Modern Frontend Stack

The project uses a modern React-based development workflow designed for fast iteration and deployment.

## 🏗️ Architecture

The project follows a component-oriented architecture where common UI elements are designed to be reusable across different sections.

```text
website_upgrade/
│
├── public/
│
├── src/
│   ├── components/
│   │   ├── Navbar/
│   │   ├── Hero/
│   │   ├── Services/
│   │   ├── About/
│   │   ├── Solutions/
│   │   ├── Contact/
│   │   └── Footer/
│   │
│   ├── pages/
│   │
│   ├── assets/
│   │
│   ├── App.*
│   └── main.*
│
├── package.json
├── vite.config.*
└── README.md
```

> The exact structure may evolve as the project continues to be improved.
